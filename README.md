## ✨ Особенности

- 📍 Текущая погода с детальной информацией
- 🌡️ Прогноз на 2 дня
- 🔍 Поиск городов по названию
- 🗺️ Сохранение множества локаций

## 🚀 Технологии

- **Kotlin** - Основной язык разработки
- **Jetpack Compose** - Современный UI toolkit
- **Material 3** - Дизайн система
- **MVI** - Архитектура приложения
- **Retrofit** - Сетевые запросы
- **Room** - Локальная база данных
- **Dagger** - Внедрение зависимостей
- **Coroutines & Flow** - Асинхронные операции

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Vladusecho/EveryWeatherPro
```

2. Откройте проект в Android Studio

3. Получите API ключ на https://www.weatherapi.com

4. В файле `gradle.properties` добавьте:
```
key=ваш_api_ключ_здесь
```

5. Соберите и запустите приложение
